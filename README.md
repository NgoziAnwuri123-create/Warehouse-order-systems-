# Warehouse Fulfilment & Shipment Processing System

## Project Overview

This project is a Python-based operational fulfilment solution designed to automate warehouse order processing, shipment calculations, and receipt generation within a logistics and delivery environment.

The application simulates a real-world warehouse operations workflow where shipment costs, order quantities, discounts, and operational charges are processed automatically to improve efficiency and reduce manual processing errors.

The solution was deployed using Streamlit to create an interactive operational dashboard accessible through a web browser.

---

## Business Problem

Warehouse and logistics operations teams often process customer shipments manually, leading to:

- Calculation errors
- Delays in order processing
- Inconsistent pricing
- Limited shipment visibility
- Manual receipt generation

This project demonstrates how operational workflows can be automated using Python to support fulfilment operations and shipment management.

---

## Solution

The application allows users to:

- Add warehouse shipment items
- Calculate shipment totals automatically
- Apply operational discount rules
- Calculate sales tax and final shipment value
- Generate digital receipt summaries
- Process operational transactions through an interactive web interface
